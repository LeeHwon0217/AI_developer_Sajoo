  • ⚠ 출구 없음 — 식상(火) 0. 머릿속엔 완성됐는데 아무도 본 적 없는 프로젝트가 있다면 그게 이 사주의 전형적인 버그입니다.
  • + 火 (용신) — 가장 중요한 패치. 배포, 데모, 블로그, 발표처럼 '보여주는 행위'가 이 사주의 막힌 출구를 뚫어요. 완성도 70%에서 공개하는 습관을 들이세요.
  • + 金 — 마감과 리뷰어를 외부에서 들여오세요. 해커톤, 공모전, 코드 리뷰를 받는 오픈소스 기여가 스스로 만들기 어려운 규칙을 대신 걸어줍니다.
