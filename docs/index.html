AI 개발자가 봐주는 사주

만세력으로 정확히 계산한 사주를, AI 개발자가 개발자 언어로 풀어드려요. 오행은 기술 스택, 대운은 릴리즈 로드맵.

신청 링크 준비 중이에요.

> 이렇게 봐드려요

시스템 스펙

사주 원국 여덟 글자를 만세력으로 정확히 계산해요.

리소스 모니터

오행 분포를 내 개발 역량 그래프로 바꿔 보여드려요.

워크 스타일

십성으로 메이커형인지, 리서처형인지 알려드려요.

릴리즈 로드맵

10년 단위 대운을 버전 태그처럼 정리해요.

> 신청 방법

  1. 양력 생년월일, 태어난 시간(모르면 비워두세요), 성별, 닉네임을 보내주세요.
  2. 개발자가 직접 분석하고 다듬어요.
  3. 나만 아는 링크로 결과 페이지를 받아요.
